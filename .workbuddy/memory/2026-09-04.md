# 2026-09-04

## 审核队列封面丢失修复（discourse-topic-cover v0.3.0）

根因：新成员首帖进入审核队列（ReviewableQueuedPost）时，`NewPostManager#enqueue`
只保存已注册的 payload 属性，`topic_opts`（携带 topic_cover_upload_id）被丢弃；
且 payload 以 JSON 存储，批准时 `create_options` 的 `symbolize_keys` 只转顶层键，
嵌套的 `"custom_fields"` 字符串键被 TopicCreator 的 `opts[:custom_fields]` 静默忽略。

修复（commit b0df0bc，本地已提交未推送，remote: limei19991-arch/discourse_required_topic_image）：
- `NewPostManager.add_plugin_payload_attribute(:topic_opts)` 注册队列字段
- `ReviewableQueuedPost.prepend(PayloadCompat)` 把 "custom_fields" 转回符号键
- `before_create_topic`：upload 无效时删除封面字段（批准路径 skip_validations 下仍校验归属）
- `on(:queued_post_created)` 给 reviewable 建 UploadReference 防孤立清理
- `on(:approved_post)` 同步 topic 侧 UploadReference（批准带 skip_events: true，topic_created 不触发）
- spec 新增 5 个审核队列用例（approve_post_count=1 触发入队；:user fabricator 默认 TL1）

注意：批准路径 `perform_approve_post` 用 `reviewable.perform(admin, :approve_post)`
（新签名：performed_by 在前）。测试需在 Discourse 开发容器跑：
`bin/rake "plugin:spec[discourse-topic-cover]"`。
用户后续流程：跑测试 → 全新普通账号实测快速首帖 → push → 服务器 `./launcher rebuild app`。
